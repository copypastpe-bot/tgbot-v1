## Выводы (по 5 файлам, 51 заказ)

- Формат стабилен: во всех файлах одинаковые 27 колонок.
- Собственный ID заказа у партнёра есть (сквозной, ~44 тыс.).
- Есть всё для матчинга: телефон (единый формат, распознан в 51/51), суммы, даты забора и сдачи, форма оплаты.
- **Отказы выгружаются отдельным отчётом** («ракета забор отказ»): статус «Забор отказ», заполнена «Причина отказа» («Не взяли трубку», «Отказ по инициативе клиента»), стоимость 0.
- Состава заказа (метраж, количество ковров) в отчёте НЕТ — только итоговая стоимость.
- «Рекламный источник = РАКЕТА» во всех 51 строках — готовый фильтр.
- Цикл заказа ~1–2 недели (добавление → забор через 2–7 дней → сдача через 5–7 дней после забора).
